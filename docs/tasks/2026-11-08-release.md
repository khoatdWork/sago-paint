Người dùng yêu cầu commit/push bản hiện tại và deploy production. Phạm vi release:
toàn bộ thay đổi Sago Paint đang chờ commit (foundation, font, skip link và trang
chủ), gồm nguồn/template, asset, test, tài liệu/skill. Không commit output/cache.
Đích hiện có: origin/main khoatdWork/sago-paint, Cloudflare Pages sagopaint;
chỉ deploy dist theo hướng dẫn AGENTS.md và SEO_AUTOMATION.md.

- `git fetch origin`: main và origin/main cùng 5c2bda6 trước release.
- `npm test` exit 0, log output/release-test.txt: toàn bộ 54 trang tại ba viewport,
  asset/font/overflow/axe, file preview, ảnh S68, calculator và navigation đạt.
- `wrangler whoami`, `pages project list`, `pages deployment list` xác nhận quyền
  Pages write, project sagopaint, domain sagopaint.vn, production main.
- Audit/review: inventory 94 files khớp dist, không docs/skills/tests/node_modules
  hoặc auth config; không phát hiện mẫu secret trong tập nguồn; file Google giống HEAD.
  CI chỉ test và lưu artifact, không deploy. Không có Must fix trước xuất bản.
- Không dùng SEO sync ghi sau commit vì lastmod phụ thuộc mtime. Đã bổ sung cách
  deploy dist trực tiếp cho commit đã kiểm thử trong SEO_AUTOMATION.md.
- Kiểm tra production/commit/deployment ID sẽ được ghi sau khi thực hiện;
